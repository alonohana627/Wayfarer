# Notes for coding agents

Wayfarer is a small action-RPG platformer (a hub town, Hearthvale, and five
regions with a guardian each; a hero who grows by experience, MapleStory-like
stats, skills and gear) in a MapleStory-inspired chibi anime look, built on
GameLib (https://github.com/alonohana627/GameLib, locally
`C:\Users\user\GameLib`; a separate repository). It is game 09 of GameLib's
platformer run (`GameLib/GAME_SUGGESTIONS/09-wayfarer.md` is its spec).

## Ground rules

- Consume GameLib only through its CMake targets (`GameLib::core`,
  `GameLib::app`, ...) and public headers (`<gamelib/...>`). Never copy GameLib
  sources into this repository or include its `src/` files. Use what GameLib
  offers (its `FEATURES.md` at the pinned commit) instead of rewriting it. The
  anime sample shaders (`shaders/avatar.frag`, `monster.frag`, `boss.frag`,
  `building.frag`, `prop.frag` and `src/app/anime_look.hpp`) started as copies
  of GameLib's `shaders/samples/anime/` - samples are meant to be copied and
  grown - and are this game's own now.
- GameLib is pinned by full commit hash in `CMakeLists.txt` (`GIT_TAG`,
  `GIT_SHALLOW FALSE`). Bump it only together with a row in
  `docs/GAMELIB_REVISION.md`. GameLib keeps no backwards compatibility.
- GameLib is changed only to fix a bug that blocks the game (GameLib commit
  with a headless test first, then a re-pin). Generic code the game had to
  write itself is kept separable and reported as a P0 candidate for GameLib's
  `FEATURE_SUGGESTIONS.md`; this repository has no feature-suggestions file.
- Snake, Tetris, Pong, Breakout, Asteroids, Invaders, Minesweeper, Leap,
  Bounder, Blaster and Cavern are read-only references.
- Every visual is generated by shaders (GameLib's built-in shapes or this
  game's `shaders/`). No image files. Every sound and the music are
  synthesized with GameLib's synth.
- MapleStory-inspired, never copied: every character, creature, place, name
  and piece of UI is an original design.
- `src/game` (rules, maps, the session, the demo bot) links only
  `GameLib::core` and `GameLib::ai`: no window, GPU, audio or clock;
  deterministic for the per-tick input. Presentation, menus, sounds and
  saves live in `src/app`.
- **Games have no tests**: no unit tests, no test executables, no
  `GameLib::testing`. The only CTest entry is the template's smoke run
  (`--hidden --require-validation --frames 120`), which enforces zero Vulkan
  validation messages on the title screen.
- Zero compiler warnings, zero shader warnings (glslc `-Werror`), zero
  validation messages.
- Small Conventional Commits (`feat(game):`, `feat(app):`, `fix:`, `build:`,
  `docs:`) after each step that builds and runs. Stage files explicitly;
  never commit build output. Never rewrite history. Push `main` to origin
  after each commit.
- `FEATURES.md` lists what the game does today, verified by running it;
  update it in the same commit as each feature; never list planned work.
- Polish is part of done: interpolated drawing, eased transitions, no
  snapping. Run the game and look at it after every visual change (GameLib's
  self-test switches plus the `win32-game-window-automation` skill). Do not
  drive F11 in automated runs: fullscreen takes over the monitor.

## Skill suggestions

Keep `SKILL_SUGGESTIONS.md` up to date: at the start of a session list
`~/.claude/skills/` and move newly installed skills to "Already installed";
add or sharpen an entry (kebab-case name, one paragraph, a "Why") whenever a
task would have gone better with a missing skill. Mention changes in one line.

## Layout

```text
CMakeLists.txt, CMakePresets.json   project, GameLib pin, presets, the smoke run
src/game/   rules -> GameLib::core (+ GameLib::ai)
            rules.hpp        the vocabulary: regions, core stats, bonuses, slots, rarities, skills, Input
            items.*          the catalogue (core::ItemRegistry), loot rolls (rarity, weighted bonuses), upgrades
            character.*      level and experience, core stats and ability points, derived values,
                             Speed and Jump as platformer tuning, skills (core::SkillBook), bag, gear
            maps.* maps_*.cpp  MapBuilder and the 21 maps: Hearthvale and five regions of four maps
            monsters.*       twenty species on eight archetypes and their brains
            bosses.*         the five guardians and their telegraphed moves
            story.*          the six townsfolk, the quests (core::QuestBook) and every conversation (core::DialogueTree)
            session.*        one playthrough: the hero (combo, hyper jump, roll, skills), monsters, drops,
                             shots, the clock, quests, dialogue conditions and effects, the shop and forge
            demo.*           the demo bot across the Bellwood Path
src/app/    presentation -> GameLib::app, ui, fx, ai, storage
            wayfarer_game.*  the Game: title + demo, slots, play, conversations, windows, travel, fainting, ending
            screens.cpp      the title, menus, controls, slots, fainting, ending and the construction sheets
            view.*           the world: camera, parallax backdrops, terrain, houses and decorations, portals,
                             people, monsters, guardians, loot, shots, the hero, lights and the color grade
            hud.*            bars, hotkeys, minimap, clock, quest tracker, toasts, the guardian's bar
            windows.*        stats, skills, bag & equipment, quest log, shop and forge
            dialogue_view.*  the conversation box with the speaker's portrait
            effects.*        arcs, sparks, damage numbers, petals, afterimages, popups, motes, shake, flash
            ui_kit.*         windows, wrapped vector text, buttons, slots, gauges, item cards
            look.*           palettes, region looks by day and night, avatars, monster colors, icons
            shapes.*         the shaders registered with the renderer, sprite builders
            anime_look.hpp   packs the anime shaders' fields (grown from GameLib's sample header)
            actions.*        the ActionMap (rebindable keys and gamepad)
            saves.*          three save slots (storage::SaveSlots) holding a game::SaveData
            profile.*        wayfarer.ini (settings, bests, key bindings, last slot, minimap size)
            sounds.*         sound recipes and the songs (a night take per region)
shaders/    avatar, monster, boss, building, deco, terrain, backdrop, fx, ui (.frag)
docs/       GAMELIB_REVISION.md
```

## Commands

```powershell
cmake --preset debug                 # configure (Ninja, Clang); downloads GameLib at the pin
cmake --build --preset debug
ctest --preset debug                 # the smoke run (validation required)
build/debug/bin/wayfarer.exe         # play; --demo plays the demo bot
$env:WAYFARER_SCENE = "sheet"        # the character construction sheets
$env:WAYFARER_SCENE = "chapter3,level15,map9,night,gear,stats"   # developer start (see applyDevScene)
```

For manual debug runs on MSYS2 set `VK_ADD_LAYER_PATH=C:\msys64\clang64\bin`
(CTest does it). `WAYFARER_DATA_DIR` moves the profile and the saves.
